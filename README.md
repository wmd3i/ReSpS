# [AAAI 2026] Re-SpS: A Reinforcement Learning Approach to Speculative Sampling

This repository contains the official code for the paper "Re-SpS: A Reinforcement Learning Approach to Speculative Sampling".

## Directory Structure

This repository is organized into two main directories (or branches):

### For Training and Testing
```bash
cd ReSpS_train_test/
```
Contains the code for training and evaluating the RL policy. Refer to the README in that directory for detailed setup and usage instructions.

### For Statistical Analysis
```bash
cd ReSps_stats/
```
Contains the code for statistical analysis of the RL policy results. Refer to the README in that directory for analysis scripts and instructions.

## Getting Started

1. Choose the appropriate directory based on your needs:
   - **Training/Testing**: Navigate to `ReSpS_train_test/`
   - **Statistical Analysis**: Navigate to `ReSps_stats/`

2. Follow the installation and usage instructions in the respective README files.
